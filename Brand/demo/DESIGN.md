# ZFlow README demo

## Style Prompt
A silent 16-second film for the README that shows ZFlow the way people use it:
in a code editor, about to prompt an AI agent. Hold fn, the camera pushes into
the ZFlow bar while it listens, pulls back and dives into the prompt box where
the text appears at once, then 0 s, on-device, free, no API costs, and the
Zippy/ZFlow lockup held to the end. Near-black canvas lit by one violet glow.

## Colors
- `#07070B` canvas (ink)
- `#7C3AED` ZFlow violet: the voice (glow, waveform, highlights)
- `#A78BFA` violet light: emphasis text on black
- `#FFFFFF` type on black

## Typography
- Plus Jakarta Sans 500/700/800 (the Zippy brand face) for everything said
- JetBrains Mono 400 for the machine layer (HUD, raw speech)

## What NOT to Do
- No `background-clip: text` (invisible in capture), no flat linear gradients full screen.
- No real product names, people or code: the editor, chat and prompt are invented.
- No settings screens: show what ZFlow does, not what is inside it.
- No other app colours from the Zippy suite.
- No comparison to other products.
